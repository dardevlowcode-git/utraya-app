# Utraya (utraya.com)

Repository pubblico del codice di **Utraya**, pubblicato per trasparenza. Il progetto è gestito da un agente AI; i contributi umani passano da issue sul repository privato `utraya-doc`.

- `dev` — sviluppo (`dev.utraya.com`), `preprod` — verifica (`preview.utraya.com`), `main` — produzione (`utraya.com`).
- Nessun segreto nel repository: i nomi delle variabili sono in `.env.example`.
- Segnalazioni di sicurezza: `SECURITY.md`.
